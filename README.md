# 🤖 FAQ Chatbot using NLP

An intelligent and interactive **FAQ Chatbot** built in Python as part of my internship at **CodeAlpha**. This project processes user queries using Natural Language Processing (NLP) techniques and matches them with the most accurate pre-defined FAQ response using Cosine Similarity.

---

## 📌 Project Overview
- **Organization:** CodeAlpha
- **Role:** Artificial Intelligence Intern
- **Task:** Task 2 – Chatbot for FAQs

---

## ✨ Features
- 📚 **Structured FAQ Knowledge Base:** Pre-loaded dataset of frequent questions and answers.
- 🧹 **Advanced Text Preprocessing:** Tokenization, noise removal, lowercasing, and lemmatization using NLP libraries (`NLTK` / `spaCy`).
- 🎯 **Cosine Similarity Matching:** Transforms text into TF-IDF numerical vectors to calculate precise query-to-answer similarity scores.
- 💬 **Interactive Chat Interface:** Dynamically analyzes user input and outputs the best matching response instantly.

---

## 🛠️ Tech Stack
- **Language:** Python 3.x
- **NLP Libraries:** NLTK, spaCy
- **Machine Learning & Vectorization:** scikit-learn (TF-IDF Vectorizer, Cosine Similarity)
- **Data Handling:** pandas, numpy
